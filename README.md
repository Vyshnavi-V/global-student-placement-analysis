# Graduate Placement and Salary Analysis Across Countries

## Project Overview
This project analyses factors influencing graduate placement outcomes and salary differences across five countries using the Global Student Placement & Salary Dataset.

## Objectives
- Analyse factors associated with graduate placement.
- Explore the relationship between CGPA and salary.
- Compare placement rates across university ranking bands.
- Examine country-wise and specialization-wise salary variations.
- Build a Logistic Regression model to predict placement status.

## Technologies Used
- R Programming
- RStudio
- ggplot2
- Logistic Regression

## Methodology
1. Data loading and exploration
2. Data preprocessing
3. Exploratory Data Analysis (EDA)
4. Data visualization
5. Logistic Regression modelling
6. Model evaluation using a confusion matrix, accuracy, precision, recall and F1-score.

## Key Results
- Total observations: 10,000
- Overall placement rate: 61.53%
- Logistic Regression accuracy: 73.6%

## Dataset
Global Student Placement & Salary Dataset – [Kaggle](https://www.kaggle.com/datasets/rakesh630/global-student-placement-2025-dataset)

**Note:** The dataset is simulated. The results should not be interpreted as actual real-world placement statistics.
