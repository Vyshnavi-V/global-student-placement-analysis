1 Introduction

Graduate placement is an important milestone in a student’s career, and salary outcomes can vary depending on several factors, such as academic performance, university ranking, internship experience, skills, and specialization. This project explores these relationships using R, descriptive statistics, data visualization, and appropriate statistical methods. The aim is to understand the patterns in graduate placement and salary outcomes and identify the factors associated with them.

2 Objectives

  1. To identify the factors associated with graduate placement outcomes.
  2. To analyse the relationship between CGPA and salary.
  3. To compare placement rates across different university ranking bands.
  4. To examine placement rates and salary variations across countries and specializations.
  5. To build and evaluate a Logistic Regression model for predicting student placement status..

3 Dataset Description

The dataset used for this project is the Global Student Placement & Salary Dataset, obtained from Kaggle. It contains information about students’ academic performance, skills, internship experience, placement status, and salary outcomes across five countries: Canada, Germany, India, the UK, and the USA. The dataset consists of 10,000 observations (rows) and 13 variables (columns). It includes three types of variables: integer, numeric, and categorical. Integer variables include backlogs and internship count, while numeric variables include CGPA, aptitude score, communication score, internship quality score, and annual salary. The categorical variables include college tier, country, university ranking band, specialization, industry, and placement status. This dataset is used to analyse the factors associated with graduate placement and salary differences across countries.

7.4 Predicting Placement Status

# Predict placement probabilities
probability <- predict(
  placement_model,
  newdata = test_data,
  type = "response"
)

# Convert probabilities into predicted classes
predicted <- ifelse(
  probability >= 0.5,
  "Placed",
  "Not Placed"
)

predicted <- factor(
  predicted,
  levels = c("Not Placed", "Placed")
)

# Create confusion matrix
confusion_matrix <- table(
  Actual = test_data$placement_status,
  Predicted = predicted
)

confusion_matrix
##             Predicted
## Actual       Not Placed Placed
##   Not Placed        460    325
##   Placed            203   1012

The predict() function calculates placement probabilities for the 2,000 test records. Using a threshold of 0.5, students are classified as Placed or Not Placed. The table() function then creates a confusion matrix to compare the actual placement status with the model’s predictions and identify correct and incorrect predictions.

7.5 Calculate accuracy

accuracy <- sum(diag(confusion_matrix)) /
  sum(confusion_matrix)

cat("Model Accuracy:", round(accuracy * 100, 2), "%")
## Model Accuracy: 73.6 %
# Calculate evaluation metrics

TP <- confusion_matrix["Placed", "Placed"]
FP <- confusion_matrix["Not Placed", "Placed"]
FN <- confusion_matrix["Placed", "Not Placed"]

precision <- TP / (TP + FP)
recall <- TP / (TP + FN)

f1_score <- 2 * (precision * recall) /
            (precision + recall)

cat("Precision:", round(precision * 100, 2), "%\n")
## Precision: 75.69 %
cat("Recall:", round(recall * 100, 2), "%\n")
## Recall: 83.29 %
cat("F1-Score:", round(f1_score * 100, 2), "%\n")
## F1-Score: 79.31 %

Precision: Of all students predicted as placed, approximately 75.69% were actually placed.

Recall: The model correctly identified approximately 83.29% of all actually placed students.

F1-score: The F1-score of approximately 79.31% represents the balance between precision and recall.

8 Conclusion

This mini project analysed the factors influencing graduate placement and salary outcomes across five countries using the Global Student Placement & Salary Dataset. The exploratory analysis revealed that factors such as CGPA, backlogs, internship experience, university ranking, country, and specialization are associated with placement and salary outcomes.

A Logistic Regression model was developed to predict student placement status. The model achieved 73.6% accuracy, with a precision of 75.69%, recall of 83.29%, and F1-score of 79.31%.

Overall, the project achieved its objectives by identifying important patterns in graduate placement and salary outcomes and developing a model to predict placement status. However, since the dataset is simulated, the findings should be interpreted as analytical insights rather than actual real-world placement statistics.
